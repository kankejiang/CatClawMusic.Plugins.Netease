## Bug 修复：插件无法退出登录/切换账号（根因在宿主）
- 现象：点退出登录后再点登录，WebView 直接显示已登录，无密码输入框。
- 根因：插件 `LogoutAsync` 只清内存 `_cookie` + 删 `netease_cookie.txt`，但宿主 `WebViewLoginPage` 打开登录页前**不清 WebView 会话 Cookie**（Android CookieManager / Windows WebView2），残留 MUSIC_U 导致网易云直接识别已登录。
- 修复（宿主仓库 `C:/Code/CatClawMusic/CatClawMusic.Maui/Pages/WebViewLoginPage.xaml.cs`）：
  - `OnAppearing` 改为 async：先 `ClearDomainCookiesAsync(CookieDomain)`，若已加载则强制重载，再 `EnsureLoginLoaded`。
  - 新增 `ClearDomainCookiesAsync`（平台分发）+ `ClearCookiesAndroid`（CookieManager 逐条过期，精准只清目标域）+ `ClearCookiesWindowsAsync`（CoreWebView2.CookieManager.DeleteCookiesAsync）。
  - 只清目标登录域，不误伤 AgentBrowserPreview 的 Bing/Baidu cookie。
- 插件侧无需改动；修复随宿主主程序发布。
- 编译验证：宿主 Windows Debug 构建通过（net10.0-windows10.0.19041.0，无 error）。坑：CoreWebView2CookieManager 没有 DeleteCookiesAsync / DeleteCookiesWithDomainOrPath（MAUI 投影版本较旧），必须 GetCookiesAsync 列表 + 逐条 DeleteCookie。
