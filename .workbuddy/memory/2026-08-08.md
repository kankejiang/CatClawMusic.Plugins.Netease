## FM 补货竞态修复（用户 Android 实测 08:02 日志，commit f90eebe 覆盖 v0.1.20 附件）
- **现象**：点漫游后，第 1/2/3 首各播 7-14 秒即切歌（解码器错误），第 3 首播完无第 4 首，继续切歌无音乐。
- **日志关键**：
  - `CCodecBuffers: Client returned a buffer it does not own` + `MediaCodec discarded unknown buffer` → **OPPO 设备 FLAC 解码器 bug**（宿主 AudioPlayerService.Android.cs OnPlayerError 注释已知坑：flac 解码器帧被丢弃→BufferPool 耗尽→杀进程）→ OnPlayerError→NotifyPlaybackCompleted→提前切歌，每首仅播 7-14 秒。

- **根因（插件侧）**：FmBufferThreshold=0 时补货只在"最后一首播完"瞬间触发，但宿主 OnPlaybackCompleted 同时执行"播完队尾即停"（PeekNextSong=null→StopAsync）→ **异步补货晚一步 → 队列空电台断**（竞态）。
- **修复**：订阅 `IAudioPlayerService.PlaybackStateChanged`（每首歌开始播 isPlaying=true 时）→ 若当前是队列最后一首（remaining=0）**立即补货**——提前一个整首歌的窗口，最后一首播完时新歌已就位，宿主切歌无缝。保留 PlaybackCompleted 事件补货 + 20s Timer 兜底（三重保险，_fmAppending 防重入）。3 首节奏语义不变（3→6 首）。

## 红心不同步"我的喜欢"排查（commit acdbc2a 覆盖 v0.1.20 附件）
- 现象：红心后网易云"我的喜欢"列表没有新歌。
- 排查结论：OpenPlaylistAsync 每次打开都重新拉服务器 tracks（不缓存）→ 列表没有 = **服务器上确实没有** → 红心请求失败。结合"推荐歌单 recommend/resource 返回空"的旁证，**用户登录 Cookie（MUSIC_U）已过期**：manipulate/tracks 被服务器拒绝（code≠200）→ LikeSongAsync false → 红心没生效。
- 修复：红心失败提示改为「操作失败，可能登录已过期，请点击右上角账号重新登录」（原"操作失败，请稍后重试"无法提示用户重登）。
- 用户行动：重新登录后红心再试；若重登后仍不同步，是网易云 playlist/detail CDN 缓存延迟（等 1-2 分钟或重进列表）。

## 红心失败真根因：csrf_token 缺失（commit a72d4da 覆盖 v0.1.20 附件）
- 用户反驳"登录过期"正确：能播 VIP 歌 = cookie 有效（播放直链 GET 校验通过）。
- 真根因：网易云老接口 `playlist/manipulate/tracks`（红心增删）的 POST 表单**必须携带 csrf_token**（取自 Cookie 的 `__csrf`），此前请求体没带 → 服务器拒绝（code≠200）→ 红心从未成功 → "我的喜欢"不同步。播放直链等 GET 接口不校验 csrf → 播放一切正常。
- 修复：`LikeSongAsync` 表单加 `csrf_token = ExtractCsrfToken(_cookie)`（解析 `__csrf`/`csrf_token` 键，缺失返回空串——服务端宽松时也可过）。FM 红心（radio/like GET）不受影响。
- 排查教训：**网易云老接口 POST 表单操作（红心/收藏/评论）都要 csrf_token；GET 查询不要**。能播会员歌 ≠ 所有登录接口都通。

## 歌手/专辑详情页返回按钮不可见修复（commit b0a9fcd 覆盖 v0.1.20 附件）

## 私人电台"听着变列表循环"修复（commit dff1046 覆盖 v0.1.20 附件）
- 现象：FM 播放中，播放模式按钮变回"列表循环"、播完循环。
