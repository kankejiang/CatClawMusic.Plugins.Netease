## 用户反馈：启用后未出现网易云子tab
- 现象：启用插件后「发现」页右侧没有出现「网易云」子 tab。
- 根因：插件侧 IDiscoverTabPlugin 已随 v0.1.1 完整实现并发布；但宿主（CatClawMusic.Maui DesktopDiscoverPage）是写死的 5 个 tab，无任何消费插件发现-tab 贡献的代码 —— 启用插件仅切换了一个宿主无渲染能力的标志。非插件 bug。
- 决策：用户再次确认「只动本插件」，暂不改动宿主仓库（CatClawMusic.Core / CatClawMusic.Maui）。tab 显示待宿主侧后续接入。
- 已就绪的接入契约（鸭子类型，零 Core 改动）：宿主对每个已启用插件实例反射探测 `string TabTitle` / `string TabIcon` / `int TabOrder` / `object CreateTabView(IServiceProvider)`（返回 MAUI View），存在即视为发现子 tab 贡献者；按 TabOrder 升序（「推荐」=0，插件=1 紧随其右）插入，选中时把 `CreateTabView(services)` 返回的 View 挂载到面板区。详细契约见 MEMORY.md。
